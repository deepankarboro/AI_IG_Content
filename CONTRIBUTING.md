# 🤝 Contributing to AI & Open-Source Hub

We welcome contributions from the community! Help us expand this byte-sized knowledge base of high-value AI tools, repositories, and prompts.

---

## 📌 How to Contribute

### 1. Add a New GitHub Repo / Tool
1. Fork the repository.
2. Navigate to `docs/github-repos/` and choose the appropriate category file (e.g., `local-llms.md`, `workflow-automation.md`).
3. Add your entry using our standard template:

```markdown
### 🛠️ [Tool Name](https://github.com/owner/repo)
> **Tagline / 1-Sentence Purpose**

- **Category:** Local LLMs | Image Gen | Audio/Speech | Automation | Dev Tools | Prompts
- **Replaces:** [Paid tool it replaces]
- **Official Repo:** [owner/repo](https://github.com/owner/repo)

#### 💻 One-Click Install / Run
```bash
# exact CLI install / run command
```

#### 📌 Quick Usage Snippet
```text
# quick starter snippet or prompt
```
```

### 2. Add New Prompt Templates
Add tested, high-leverage prompt templates under `docs/prompts/`.

### 3. Open a Pull Request
1. Commit your changes: `git commit -m "feat: add [Tool Name] to local-llms"`
2. Push to your fork and open a Pull Request.
3. Once reviewed, your contribution will be merged and automatically deployed!
